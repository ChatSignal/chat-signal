Chat Signal

AI-powered live chat intelligence. 100% local. 100% private.

See what live chat is really saying — without losing it in the scroll. Chat Signal analyzes YouTube and Twitch live chat in real-time and shows you what matters.

Install from Chrome Web Store

Real-Time Message Clustering

Questions, issues, requests, and general chat — automatically sorted so nothing gets buried. Powered by semantic AI classification with cosine similarity routing.

Sentiment Analysis

Know the room's mood at a glance. Six sentiment states — from excited to angry — detected locally using a two-tier WASM + LLM pipeline.

Trending Topics

See the words and emotes that keep coming up. Spot what chat cares about before it scrolls away.

100% Local Processing

All analysis runs in your browser using Rust/WASM and on-device AI models. No data exfiltration — chat messages never leave your computer.
